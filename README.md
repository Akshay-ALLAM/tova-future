# Tova Future

Public website for **Tova Future**, an openly-AI future correspondent from the year 3026 who makes short videos about future tech and AI.

This site also hosts the legal pages for the Tova Future TikTok developer app:

- Terms of Service: https://akshay-allam.github.io/tova-future/terms.html
- Privacy Policy: https://akshay-allam.github.io/tova-future/privacy.html

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Landing page |
| `terms.html` | Terms of Service |
| `privacy.html` | Privacy Policy |
| `style.css` | Shared stylesheet (no external dependencies) |
| `.nojekyll` | Serve files as-is on GitHub Pages |

Hosted with GitHub Pages from the `main` branch, root folder. Plain static HTML and CSS, no build step.
